# Superstore Sales Dashboard

## Project Overview
An interactive sales dashboard created using Excel and the Superstore Sales dataset to analyze sales performance and trends.

## Features
- Total Sales KPI
- Total Records
- Sales by Category
- Sales Trend Over Time
- Conditional Formatting
- Interactive Slicers
- Category, Region, Segment and Ship Mode filters
- Pivot Tables and Pivot Charts
- Interactive Dashboard

## Tools Used
- Microsoft Excel / WPS Office
- Pivot Tables
- Pivot Charts
- Conditional Formatting
- Slicers
- Superstore Sales Dataset

## Key Insights
- Total Sales: $2,261,536.78
- Total Records: 9,800
- Top Category: Technology
- Top Region: West

## Note
Profit analysis is unavailable because Profit/Cost data was not included in the provided dataset.
